# Sistema IMC FullStack

Uma API RESTful construída com express, TypeScript e TypeORM, utilizando Sqlite como banco de dados e FrontEnd construído com NextJS e TypeScript.

## 🚀 Tecnologias Back-end

- **Express** - Framework web rápido e eficiente
- **TypeScript** - Superset do JavaScript com tipagem estática
- **TypeORM** - ORM moderno para TypeScript e Node.js
- **Sqlite** - Banco de dados
- **Zod** - Validação de schemas
- **JWT** - (JSON Web Token) & Refresh Token


## 🚀 Tecnologias Front-end

- **React** - Biblioteca JavaScript para construção de interfaces
- **NextJS** - Framework React para aplicações com renderização híbrida (SSR/SSG)
- **TypeScript** - Superset do JavaScript com tipagem estática
- **Chakra UI** - Biblioteca de componentes UI para React
- **React Query** - Gerenciamento de dados assíncronos e cache
- **React Hook Form** - Biblioteca de formulários
- **Axios** - Biblioteca para fazer a requisição dos endpoints do backend

<br />
Siga o guia de instalação e configuração para preparar o projeto para execução.

## 🔧 Scripts para rodar o projeto

- `yarn` - Inicia instalação de todas as dependencias do projeto.
- `yarn migration:run` - Executa a migration inicial para poder rodar o back-end.
- `yarn seed` - Executa script para criar uma conta de admin.
- `yarn dev` - Inicia o servidor em desenvolvimento.

- Após rodar em desenvolvimento pode rodar em produção.
- `yarn build` - Compila e faz bundle do TypeScript.
- `yarn start` - Inicia o servidor em produção.
